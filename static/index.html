每天自动备份一次（订单、生产、库存、产品资料、图片、模型、切片文件、设置），保留最近 30 份。建议每周下载一份存到别的地方（电脑 / U 盘 / 网盘）。 恢复方法：关掉程序，把备份 zip 解压到 data 文件夹覆盖，再启动。点「检查」可以确认这份备份能正常恢复。

系统检查与升级

在线更新（GitHub）

新版本发布到 GitHub 后，NAS 每天自动检查一次，有新版本会在这里和顶部提示；点「立即更新」才会升级（先自动备份程序，数据不会动，升级后自动重启）。 仓库名和只读令牌在 设置 → 通用 → 在线更新。

上传升级包

收到新版本的压缩包后，直接在这里上传就能升级，不用再到 NAS / 电脑里手动覆盖文件。 Windows 版和 NAS 版的压缩包都可以用。升级前会自动备份当前程序（在「数据备份」文件夹里，名字以 app_v 开头），数据不会动。

浏览器 AI 客服扩展（在卖家中心聊天页面直接用 AI）

⬇ 下载扩展

装了扩展，员工可以在 Lazada / Shopee / TikTok 卖家中心的聊天页面直接用 AI 读取消息、写回复（手动 / 半自动 / 全自动）。每个员工用自己的密钥连接本系统。

  1. 下载后解压到一个固定的文件夹（不要删）。
  2. Chrome 地址栏打开 chrome://extensions → 右上角打开「开发者模式」→「加载已解压的扩展程序」→ 选刚才解压的文件夹。
  3. 老板在 设置 → 账号与权限「员工的扩展密钥」里给每个员工生成一个密钥。
  4. 点 Chrome 右上角的扩展图标：填局域网地址（例如 http://NAS的IP:8790）、外网地址（Tailscale，可不填）和密钥，选面板语言，点「保存并测试」。
  5. 打开 Lazada / Shopee / TikTok 卖家中心的聊天页面，右上角有「💬 AI」按钮：读取对话 → 检查回复 → 填入回复框 → 在平台按发送。

每个店铺用自己的浏览器窗口登录（多个店铺可以用 Chrome 的不同「用户」）。账号密码只在浏览器里，扩展不会读取。勾选「自动」后，买家发新消息时会自动读取并写好回复草稿，仍然由员工按发送。
