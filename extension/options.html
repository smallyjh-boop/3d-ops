选品（模型网站） ?
…
在 MakerWorld / Printables / Thingiverse 的列表页，每个模型左上角有推荐分和「＋采集」（＝在 ERP 里采用，马上建产品草稿）。插件在后台按 ERP 定的节奏读详情页、用这台电脑浏览器里原站的登录状态下载模型文件、按关注列表巡逻；遇到人机验证 / 请求太频繁会自动暂停这个网站。结果在 ERP「商品 → 选品」。
设置
在卖家中心 / BigSeller 下载面单 PDF 时弹出提示，点「发送到系统」才发。有的平台点「打印面单」是在新标签页打开 PDF：在那个标签页点上面的「📄 发送当前 PDF」。系统按每页上的订单号 / 运单号自动对应订单。
打开卖家中心的数据页面（商品表现 / 流量 / 关键词）时自动采集，同一页 12 小时一次。在 Lazada / Shopee / TikTok 的商品页、搜索结果页、店铺页，右下角有采集按钮，列表里每个商品卡片左上角有「📊 采集」。今日巡逻：人在电脑旁时用，按系统里的清单一页一页看，每天有上限，遇到验证码马上停。结果在系统「商品 → 竞品 / 爆款雷达 / 竞店」和「工作台 → 流量数据」。
选品（模型网站）
每分钟问一次 ERP 有没有活，一次只开一个后台标签页，读完就关。要这台电脑开着、Chrome 开着；在原站登录过才能下载要登录的文件。关掉就不再自动做（列表页的推荐分照样显示）。
AI 客服（聊天页右下角的面板）
和聊天页面板里的开关是同一个设置，改了以后刷新聊天页生效。每个聊天页的模式（关 / 半自动 / 全自动）在面板里选。
