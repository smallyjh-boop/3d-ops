3D 运营管理系统 v2.13 —— 使用说明（原名「上新助手」）
==========================

一、第一次安装（只做一次）
1. 把整个文件夹解压到一个固定位置，例如 D:\3D 运营管理系统\
   （不要直接在压缩包里双击运行）
2. 双击 1_setup.bat
   - 它会检查 Python 版本、创建独立运行环境、安装依赖，最后做一次环境自检
   - 如果提示没有 Python：到 https://www.python.org/downloads/windows/ 装 Python 3.12，
     安装时勾选 "Add python.exe to PATH"，再双击 1_setup.bat
3. （可选）双击 3_install_bg_removal.bat 安装 AI 去背景组件

二、日常使用（装到 NAS 给局域网所有人用：见 NAS_SETUP.txt）
双击 2_start.bat → 浏览器会自动打开 http://127.0.0.1:8765
关闭黑色窗口 = 退出程序。所有数据保存在 data 文件夹，请定期备份这个文件夹。

三、首次设置（设置页）
1. AI 文案：填接口密钥。
   - 用 Claude：接口类型 anthropic，模型 claude-sonnet-5-5，密钥在 console.anthropic.com 申请
   - 用 DeepSeek 等：接口类型 openai_compatible，接口地址 https://api.deepseek.com，模型 deepseek-chat
2. 图床：到 https://api.imgbb.com/ 注册，免费获取 API key，填到「imgbb 图床密钥」
3. 成本、平台扣点按实际情况核对（平台扣点 0.2 只是占位值）

升级旧版本：先关闭所有黑色窗口，再把新压缩包解压后整个覆盖到原来的文件夹（选「替换」），然后双击 2_start.bat。
（从 v0.7.1 起，启动时如果发现旧版本还开着会自动关掉它；页面顶部出现红条提示「后台还在运行旧版本」时，按提示重启即可。）
data 文件夹（你的产品、设置）和 .venv 不会被覆盖，不用重新安装。

四、编码规则
产品编码：前缀 + 4 位顺序号（3DP0001、3DP0002…），删除的号码不会再用。
SKU：产品编码-颜色代码-规格代码，例如 3DP0001-WH、3DP0001-BK-L。
颜色代码表在设置页修改。导出过 Lazada 的产品 SKU 自动锁定。
产品库右上角「导出全部产品资料」= 一个 Excel，含 SKU 明细、产品汇总、颜色代码表。

五、上新流程
1. 产品库 → 新建产品
2. 填中文名称、用途卖点、尺寸、包裹尺寸
3. 变体表：填每个款式的克数和打印时长（有 3D 模型时可用第③步自动填，见第八节），价格自动算出；
   想按市场定价，就在「手动售价」填价格，工具会显示实际加价率
4. 上传图片 → 「全部转成 1:1 白底方图」（或去背景）→ 选一张「设为白底图」
5. 「AI 生成文案」→ 对照右边中文回译检查，有问题直接改泰文，再点「重新回译」
6. 「上传图床，生成网址」
7. ⑥ 点「AI 匹配类目并填写属性」：AI 从你的模板库里选类目、填属性、估包裹尺寸
   红框 = AI 不确定或必填缺少：值没问题就点该项的「✓ 确认」（或右上角「✓ 全部确认」），
   不对就直接改选；你确认或改过的值，下次同类目自动套用
8. ⑦ 上架检查全部通过（显示「可导出」）
9. 导出 Lazada 表格：勾选产品 → 生成导入表格（按类目自动分文件）→ 下载
10. Lazada 卖家中心 → 批量管理 → 上传表格 → 查看处理结果
11. 在 BigSeller 用「产品搬家」把 Lazada 产品复制到 Shopee / TikTok Shop

六、Lazada 类目模板（已内置，不用自己下载）
已内置 27 个适合 3D 打印产品的类目模板：花瓶、摆件雕像、手办收藏、花盆、夜灯、手机支架、
耳机/音箱支架、游戏配件、理线器、桌面收纳、收纳盒、厨房收纳、浴室置物/挂钩、解压玩具、
益智游戏、骰子桌游配件、Cosplay 道具、宠物玩具、墙面装饰/相框、车载手机支架、手动工具配件、洗衣机/熨斗/烘干机配件，
以及水暖五金 5 类（水管/软管、水管配件接头三通、存水弯/排水配件、洁具零件阀门、洗手池和排水管）。
工具里还内置了 Lazada 泰国站完整类目树（2727 个类目）。产品不属于以上类目时，
AI 会给出理想类目和类目ID，下载那个类目的模板后在「导出」页上传即可（也可以让 Claude 代办）。
注意：夜灯、解压玩具这两个类目 Lazada 要求泰国 TISI 认证许可证号，没有许可证请不要用。

七、Shopee 导出
已内置 Shopee 批量上传基础模板和 Shopee 泰国站完整类目树（1442 个类目）。
编辑产品第⑥步下面有「Shopee 类目」：点「AI 匹配 Shopee 类目」；或输入中文/泰文/英文关键词回车搜索后点结果；
也可以用「逐级选择」一级一级选到最末级。内置 Shopee 泰国站完整类目 2042 个。
确认过的对应关系会被记住：同一个 Lazada 类目下次自动对应到同一个 Shopee 类目。
第⑦步上架检查分 Lazada / Shopee 两栏；导出页点「生成 Shopee 导入表格」。
上传：Shopee 卖家中心 → 我的产品 → Mass Function → Mass Upload → Upload File。
注意：Shopee 账号身份验证（KYC）通过后才能发布产品；基础模板不含品牌等属性，上传后可能需要在 Shopee 后台补。
Shopee 扣点和 Lazada 不同时，在设置页「Shopee 扣点」单独填写，导出 Shopee 时按它定价。

八、3D 模型：自动算克数时长、自动出商品图（第③步）
1. 点「上传模型文件」选 .stl 或 .3mf，可以 360° 拖动查看，自动显示尺寸和体积。
   「填入产品尺寸和包裹尺寸」一键填好尺寸（包裹每边加 1.5 cm，请按实际包装核对）。
2. 克数/时长有三种来源（变体表里会标「估」或「切」）：
   a) 估算：上传模型后马上有，误差约 ±30%，只适合先报价。上架检查会黄色提醒。
   b) 导入切片文件：在 Bambu Studio / OrcaSlicer 切片后「导出切片文件」（.gcode.3mf 或 .gcode），
      点「导入切片文件」，数值准确。每导入一次，估算会自动校准，越用越准。
   c) OrcaSlicer 自动切片：需要先在设置页配置（见下）。
   出结果后可选「填入全部变体」或只填某个变体。
3. 一键生成商品图：勾选「每个颜色一张主图 / 多角度 / 尺寸标注图 / 第一张设为白底图」，
   点「一键生成商品图」。颜色取自变体表的颜色，每个颜色的图会自动设为该变体的图片。
   想要特别的角度：拖到满意的角度，点「用当前角度拍一张」。
   再次生成会替换上次生成的图，你自己上传的实拍图会保留。生成后记得点「上传图床」。
4. OrcaSlicer 自动切片设置（设置页 →「打印机与 OrcaSlicer 配置文件」）：
   - 点「查找 OrcaSlicer 和配置文件」：自动从安装信息、开始菜单/桌面快捷方式、各硬盘常见目录找程序，
     找到后自动记住。找不到就点「手动选择程序…」，在弹出的窗口里选 orca-slicer.exe
     （或桌面上的 OrcaSlicer 快捷方式），窗口可能在浏览器后面；
   - 点「自动匹配配置」：按打印机名称自动选好 OrcaSlicer 自带的打印机/工艺/耗材配置
     （P1S、K1 Max、K1C 都能自动识别，不需要先在 OrcaSlicer 里保存预设）。
     想用自己调好的预设：在输入框里点一下，从列表里选（自己保存的预设也会列出来）；
   - 产品材质是 PETG/TPU/ABS 等时，切片会自动换成对应材质的耗材配置；
   - 点「测试切片」，成功会显示 20mm 立方体的克数和时长；失败请把日志截图发给我。
   - 没装 OrcaSlicer 也没关系，用 b) 导入切片文件即可。
5. 颜色代码表每行可以加第 5 项渲染颜色（如 荧光绿, GN, เขียวนีออน, Neon Green, #39FF14），
   不填时按颜色名自动猜。第②步「点选颜色」点色块即可添加/删除颜色变体；3D 预览下方也能点色块换颜色。
6. AI 打印建议 + 产品描述（第③步下方）：
   - 可写一句提示词（例：放车里用、给小孩玩、要软），点「AI 分析并生成建议」；
   - AI 会结合模型几何分析（6 个摆放方向的悬空面积、底面接触、高度）和渲染图，给出：
     用途/卖点描述（可一键填入①，不会提制造方式）、建议材质（考虑泰国高温）、摆放方向、
     层高、壁数、填充率/图案、支撑、帽檐、风险和后处理（中泰双语，员工可直接看）；
   - 勾选「估算和 OrcaSlicer 自动切片按这些参数」后，估算克数和自动切片都会用建议参数；
   - 「导出全部产品资料」的产品汇总表里有一列打印建议，可以打印给员工生产用。

九、场景图（第④步图片下方「场景图」）
商品图和场景图都不带阴影（干净的产品，合成时不会有难看的影子）。
1. 背景库（所有产品共用）有两种来源：
   ① 自己拍：用手机拍书桌、书架、床头柜、客厅茶几等（台面空着、光线柔和、正方形构图），点「上传自己的背景照片」。最真实，免费。
   ② AI 生成背景：点选电商常用场景（木质书桌、白色办公桌、客厅茶几、床头柜、书架、厨房/浴室台面、咖啡店、花园、
      儿童房、节日礼物、车内、浅色简约台），点「生成选中的背景」。生成的是不含产品的空背景，只生成一次，
      以后所有产品都能用，所以不会画错你的产品；每张约 0.4-2 铢。不满意的点背景右上角 ✕ 删除。
2. 合成：选产品来源（3D 模型可选颜色，或任意一张白底图自动抠图）→ 点选背景 → 拖动位置、滚轮调大小 →「加入商品图」。
   勾「多个颜色并排放」可做颜色合集图。调好位置后可点「记住这张背景的摆放位置」。
3. AI 生成场景图（把产品放进场景，按张收费）：选场景和补充要求，点「AI 生成场景图」。
   AI 可能把产品画得和实物不一样，请逐张检查，不一致的删掉。
4. 图片 AI 模型：留空就用最便宜的（OpenAI：gpt-image-1-mini；Google：gemini-3.1-flash-lite-image），
   想要效果更好可填 gpt-image-1 或 gemini-3.1-flash-image。
5. 场景图排在主图后面；「全部转成白底方图」不会处理渲染图和场景图。
   旧的带阴影的渲染图：在③重新点「一键生成商品图」即可替换。

十、关键词扩展（第⑤步「AI 关键词扩展」）
按 Lazada / Shopee 泰国站的搜索习惯，把买家可能搜的词尽量找全：核心词、同义词/口语/不同写法、英文词、
属性词、场景/用途、人群/送礼、长尾词，并列出不能用的词（品牌/IP 等）。结果自动补进①的「关键词」。
「AI 生成文案」会按这些词来写：标题以主词开头、放最重要的词并保持通顺；其他词自然地写进详情
（「เหมาะสำหรับ」适用场景、送礼等）；另外单独生成 Shopee 标题（≤120 字符）和 Shopee #标签（会被搜索）。
关键词面板里：绿色=已在标题里，蓝色=在详情/英文/标签里，灰色=还没用上；可删除不合适的词、添加自己的词，
改完再点「AI 生成文案」重新生成。没先点扩展时，生成文案会自动先扩展一次。

AI 用哪家：文案、关键词、类目属性、打印建议都用设置页「AI」里的接口——Anthropic，或任何 OpenAI 兼容接口
（DeepSeek、通义千问、Kimi、豆包、OpenAI 等，填接口地址和模型名即可）。只有「AI 生成场景图」需要能画图的模型
（OpenAI gpt-image-1 或 Google Gemini），不用它也可以用免费的背景合成。

十一、账号与权限（v0.9 新增）
- 装在 NAS 上：第一次打开会要求创建「老板」账号，之后都要登录。
- 在自己电脑上单机用：默认不用登录；在「账号」页给自己建了老板账号后，就需要登录。
- 「账号」页（只有老板能看到）：给员工开账号、改角色、改界面语言、停用、重设密码；下面是操作记录。
  · 上架客服：产品、图片、AI 文案、类目、导出；看不到成本、利润、加价率和设置，也看不到 AI 密钥。
  · 生产打包：能看产品、3D 模型、切片、打印建议；看不到价格，不能改产品。可以看订单（不含金额）、生产看板、耗材库存。
- 每个账号可以有自己的界面语言；员工登录后自动用泰文。右上角可以改密码、退出。
- 忘记老板密码：用另一个老板账号重设；只有一个老板账号时，删除 data/app.db 里的账号需要找开发者处理，请把密码记好。

十二、订单、生产、耗材、利润（v1.0 新增）
1. 订单页
   - 从 BigSeller（或 Lazada / Shopee / TikTok 后台）导出订单 Excel/CSV，点「导入订单表格」。
   - 第一次导入：系统自动猜每一列是什么，检查一下（必须有「订单号」和「SKU」），填个名字记住格式。
     以后同样格式的表格会自动识别，直接点「确认导入」。
   - 同一批订单重复导入不会重复，只更新状态（例如已发货、已取消）。已取消的订单，还没打印的任务自动删掉。
   - SKU 要和产品库里变体的 SKU 一样才能对上产品（会自动去掉平台加的前后缀）。对不上的会列出来，
     在产品里改好 SKU 后点「重新匹配 SKU」。
   - 手工订单：批发/大单、定制单、私下成交、报价单。「定制要求」（刻字、颜色、包装等）会显示在生产任务上。
     报价单会排进生产计划（看什么时候能交货），但不算收入。
   - 点订单可以看详情、写定制备注、标加急、改状态；老板还能看到这一单的利润。
2. 生产页（给生产员工用，泰文界面）
   - 待发货订单的每个商品自动变成一个打印任务，按「加急 → 最晚发货时间 → 下单时间」分配到最快能完成的打印机，
     同颜色的尽量排在一起少换料。
   - 员工按按钮：开始打印 → 打印完成 → 已打包 → 已发货。打印失败点「失败」，任务回到队列。
   - 想换打印机就在任务上选「换打印机」，之后排单不会再改它。
   - 「来不及！」表示预计完成时间晚于平台最晚发货时间。
   - 产品没有切片（缺克数/时长）的任务排单时间不准，也不能自动扣耗材。
3. 耗材页
   - 第一次用：每种颜色现有多少公斤，「盘点」录入一次。以后打印完成/失败自动扣，买料到货点「入库」。
   - 采购建议按最近 7 天和 30 天的用量（取较大）加上还没打印的任务需要的量来算；
     到货天数、安全库存天数、每次买几天的量、每卷几公斤在 设置 → 耗材采购 里改。
4. 利润页（只有老板能看）
   - 每单利润 = 收入 − 平台费用 − 材料 − 机时 − 包材 − 失败损耗；每日利润再减去当天手动记的广告费等支出。
   - 导入的表格里有佣金/手续费列就用真实数，没有就按设置里的扣点估算。
   - 已取消、退款、未付款、报价单不计算。商品没对上或缺克数的订单会提示，成本会偏低。

5. 对外接口与店铺自动导入（v1.1 新增，老板在「账号」页最下面「API 与店铺对接」）
   - 现在先用表格导入订单。以后有两种方式让订单自动进来，效果和表格导入完全一样
     （同一订单不重复、对上 SKU、自动生成生产任务、算利润）：
     ① 店铺对接：添加店铺，填平台开放接口的授权信息，打开「自动同步」，系统每隔几分钟自动拉订单。
        Lazada、Shopee 已经写好，拿到开放平台的 App Key 后联调；TikTok Shop 先预留位置。
     ② API 推送：创建「API 密钥」，外部程序（自动化工具、自己写的脚本）调用 POST /api/v1/orders 推送订单。
        接口说明点「接口说明」按钮查看（地址 /api-docs）。
   - 每次同步和每次平台推送都有记录，出错原因会显示在店铺那一行。
   - BigSeller 没有公开的订单接口，继续用导出表格导入即可。
   - 平台主动推送（webhook）需要 NAS 能从公网访问；只在局域网里用的话，用定时同步就够了。

6. 打印机连接与打印文件库（v1.2 新增，「打印机」页）
   - 连接打印机（老板在每台打印机卡片里点「连接设置」）：
     · 拓竹 P1S：填 IP、序列号、访问码（打印机屏幕 设置 → 网络 / 设备信息）。新固件要在打印机上打开
       「局域网模式」和「开发者模式」，否则只能读状态，不能由本系统发送打印。
     · Creality K1 Max / K1C：填 IP，连接方式选「自动识别」。原厂固件和 root 过的（Fluidd/Mainsail）都支持。
       原厂固件的「上传文件」是按 Creality Print 的做法写的，需要在你的打印机上实测；不行的话先用 Creality Print
       把文件传上去，生产页点「已开始打印」也能照常记录。
     · 点「测试连接」，显示连接成功后，卡片上会实时显示：在打什么、进度、剩余时间、温度、AMS 料盘颜色和剩余。
     · 可以暂停 / 继续 / 取消打印。没有 AMS 的打印机，员工在卡片里填「现在装的料」。
   - 打印文件库：每个产品（或某个 SKU）在每台打印机上用哪个切片文件、一盘放几个。
     · 上传 Bambu Studio / OrcaSlicer 导出的切片文件（.gcode.3mf，一个文件一个盘），Creality 用 .gcode。
     · 或者点「用 OrcaSlicer 自动切片生成」（一盘 1 个）。一盘多个的，在切片软件里排好版导出后上传，填「一盘放几个」。
     · 订单数量超过一盘时自动分几盘打；不同打印机速度不同，排单按各自文件的时长算。
   - 生产页：有文件、打印机已连接的任务，出现「📤 发送到打印机」按钮。发送前会确认热床已清空；
     料盘颜色和订单颜色对不上会提醒。打印机报告完成后自动记一盘、自动扣耗材，全部打完进入「后处理」。
     打印机报告失败/取消会在任务上标红，员工确认后点「失败」（重新排队）或「打印完成」。

7. 订单页（v1.2 改为 ERP 方式）
   - 上方分栏：待生产 / 生产中 / 待发货 / 已发货 / 已完成 / 未付款 / 报价 / 已取消 / 售后 / 异常，每栏有数量。
   - 「异常」自动找出：SKU 没对上、产品没切片、快到/已过最晚发货时间、排产来不及、打印机报警、打印失败。
   - 筛选：平台、店铺、类型、标签、下单日期、关键词（订单号/买家/SKU/运单号/备注），可排序、分页。
   - 勾选后批量：打印拣货单（同 SKU 同颜色合并数量）、打印装箱单（每单一页，带定制要求）、标记已发货/已完成、
     加急、加/去标签、取消订单、导出 Excel、删除（老板）。
   - 订单详情可改运单号、标签、最晚发货时间；下面有这一单的完整操作记录（导入、状态变化、打印、发货…）。

8. 耗材预测（v1.2）
   - 每天用量取「实际消耗（近 7/30 天）」和「按订单销量预测（近 14 天权重大）」中较大的。
   - 待打印任务还要的料按打印文件（每盘克数 × 剩余盘数）计算。
   - 显示：还能用几天、预计哪天用完、最晚哪天要下单（到货天数 + 安全天数）、未来 N 天共需要多少、建议买几卷、主要用在哪些 SKU。
   - 发送打印时，如果库存记录不够这一盘会提醒（库存记录可能和实际有出入，以实际为准）。
   - 「打印机上的料」显示拓竹 AMS 料盘颜色和剩余，以及其他打印机填写的颜色；排单会优先把同颜色任务排给已经装着这个颜色的打印机。

9. 面单（v1.3 新增，订单页）
   - 平台面单：在 Lazada / Shopee / TikTok 卖家中心或 BigSeller 批量下载面单 PDF，在订单页点「⬆ 上传平台面单 PDF」，
     系统按每页上的订单号/运单号自动拆开、对应到订单（订单列表会显示「🏷 有平台面单」）。
     勾选订单 → 「🏷 打印面单」，合并成一个 PDF 直接打印，并记录「已打面单」（可以按「未打面单」筛选，防止漏打）。
   - 自制面单：没有平台面单的订单（手工单、私下成交、自己找快递）打印 100×150mm 热敏面单：收件人、电话、地址、
     邮编、物流公司、货到付款金额、运单号条形码、订单号条形码、商品和定制要求。寄件人在 设置 → 发货 里填写。
   - 导入订单时，表格里的收件人、电话、地址、邮编、物流公司、货到付款金额会自动识别；订单详情里也可以修改。
   - 以后接上平台开放接口，可以直接从平台取面单，不用再上传 PDF。

10. 操作日志（v1.3 改为单独一页「操作日志」）
   - 按天分组，可以折叠/展开，按账号、时间、关键词筛选，默认不显示登录记录。
   - 每个订单自己的操作记录在订单详情最下面（默认收起）。

十三、v2.0 新功能
1. 菜单：顶部 6 个模块（首页 / 商品 / 订单 / 生产 / 经营 / 系统），每个模块下面是子页面。
   商品 = 产品库 + 编辑产品 + 导出表格；生产 = 生产看板 + 打印机 + 打印配方 + 耗材 + 成品备货 + 质量统计。
   生产员工登录后只看到生产相关页面，默认打开生产看板。
2. 产品分组与搜索：产品库左侧是分组栏，可以新建/改名/删除分组；勾选产品 → 「加入分组」。
   搜索框可以搜编号、中文/泰文品名、关键词、颜色、材料。一个产品可以属于多个分组。
3. 打印配方（编辑产品 → 打印配方，或 生产 → 打印配方）：
   - 系统自动分析模型 6 个摆放方向（底面朝下/顶面朝下/正面/背面/左/右），显示悬空面积、是否需要支撑、一盘能放几个，推荐一个。
   - 设置层高、填充、支撑（无/普通/树状，仅接触热床）、裙边、热床类型、间距、备注（会显示在生产工单上）。
   - 点「切片」按配方自动切片；第一次满盘切片时系统会学习这台打印机真实的满盘数量。
4. 切片文件审核（防止打印失败）：
   - 状态：草稿 → 已人工复核 → 已试打验证（✅ 标记）。
   - 每个文件先自动检查（尺寸超出、支撑、首层面积、重量与预估差异等），再点「AI 复核」，最后由人工逐项勾选：
     支撑、摆放方向、数量、参数、材料 —— 全部确认后才算「已复核」。
   - 试打成功后点「试打验证」，可以上传成品照片，以后优先用这个文件。
   - 没有试打过的文件，开始打印前对话框里会再要求人工确认一次。
5. 开始打印（生产看板 → 任务卡 →「开始打印」）：
   - 数量模式：按订单（默认）/ 满盘 / AI 建议 / 指定数量。多出来的成品自动进入成品库存。
   - 同一产品、同颜色的其他订单可以勾选「合并到一盘」。
   - 每次提交前必须勾选「热床已清空」才能发送。
   - 打印机已连接可以一键发送并开始；未连接可以选「手动打印」，打完回来点完成。
6. 打印批次：每一盘是一个批次，完成后自动扣耗材、更新各订单已完成数量；
   失败时选择失败原因（翘边、拉丝、断料、堵头、支撑问题、层错位…），按进度扣耗材，任务回到待打印。
7. 质量统计：按打印机/产品/原因统计失败率，找出问题机器和问题产品。
8. 打印机保养：按打印小时数提醒（50 小时清洁热床/喷嘴外部、200 小时导轨润滑/检查皮带、500 小时检查或更换喷嘴），做完点「已保养」。
9. 耗材受潮提醒：耗材页可记录「开封」「已烘干」，开封超过天数会提醒烘干（PLA 30 天、ABS/ASA 15 天、PETG 7 天、TPU/PC 3 天、尼龙/PVA 2 天）。
10. 成品备货（只提醒，不自动生产）：
   - 按近 30 天销量建议备货数量（覆盖天数和最低销量在 设置 → 订单与备货）。
   - 建议在打印机空闲时段打，避开正常订单；由你决定点「生成备货任务」才会进入生产。
   - 有现货的订单任务可以点「用库存」直接出货，不再打印。
11. 发货天数：每个产品可以设置「发货天数」，没设置用 设置 → 默认发货天数，订单导入后自动算出最晚发货日。
12. 售后：订单详情 →「登记售后」（退款/补发/重做），补发会自动生成生产任务；订单 → 售后 页面集中查看和关闭。
13. 打包扫码（订单 → 打包）：用扫码枪或手机/平板摄像头扫订单号或工单条码，再扫商品条码核对，
   拿错商品会红色提示并响一声，全部核对完点「打包完成」。
14. 工单：生产卡片可打印 60×40mm 工单（图片、编号、中泰品名、颜色、备注、配方备注、条码），贴在成品上方便打包核对。
15. 首页看板：今日待发、超时、打印中、失败率、耗材告急、备货建议、保养提醒一目了然。
16. 自动备份：每天自动备份数据库到 data\backups，保留最近 30 份；系统 → 备份 也可以手动备份和下载。
17. 手机/平板：生产看板、打包页面已适配手机和平板，员工可以在打印机旁边直接操作。

18. 打印材料与切片参数（v2.1）
   - 打印方案最上面是「打印材料」（PLA / PETG / TPU / ABS / ASA / PLA-CF / PETG-CF / PA / PC），和产品的「材料」是同一个。
     切片会自动用这种材料的耗材配置；也可以在「切片配置」表里给每台打印机指定自己在 OrcaSlicer 里调好的耗材配置。
   - 可以填喷嘴温度、热床温度（空着 = 按耗材配置），支撑角度（悬空小于这个角度就加支撑）。
   - 每个切片文件都会读出实际参数：材料、耗材配置、喷嘴/热床温度、热床板、层高、壁数、填充、支撑类型和角度、帽檐、速度。
     材料和产品材料不一样 → 红色「材料不对」，不能复核、不能开始打印；温度不在这种材料的常用范围、参数和方案不一致也会提醒。
   - 产品换了材料以后，旧材料的切片文件自动不能再用，需要重新切片。
   - 开始打印时显示「这一盘要用：PLA 白色」和切片文件的材料、温度，必须勾选「打印机里装的是 PLA 白色」才能开始；
     拓竹读到料盘材料不一样时会拦住（料盘读数不准时可以勾选确认）。生产看板的任务卡上也显示材料。
19. 实时预览与 3D 切片预览（v2.1）
   - 打印方案左边是实时 3D 预览：改摆放方向、支撑、角度、帽檐、一盘数量、间距，马上看到效果，不用保存。
     蓝色 = 贴热床，红色 = 悬空但没加支撑（可能会塌），橙色 = 悬空有支撑，绿色 = 支撑大概的位置；一盘放几个按所选打印机热床排版。
     （实时预览是示意，真实的支撑以切片结果为准。）
   - 切片文件上点「🔍 3D 切片预览」：看切片软件实际生成的路径，外墙、内墙、填充、支撑、帽檐用不同颜色，
     可以拖动滑块一层一层看（或只看某一层），可以单独隐藏某种类型（例如隐藏填充只看支撑）。右边是材料、温度和全部切片参数。
   - 按方案切片、上传文件后会自动打开切片预览；开始打印对话框里也可以打开。

十四、AI 客服（v2.2 新增，独立模块）
顶部菜单「客服」：客服工作台、知识库与话术。老板和上架客服账号能用，生产账号看不到。
客服是一个独立模块（程序里的 core/cs 文件夹），只通过一个连接文件读产品、订单，写订单备注、生成报价单，
以后单独调整客服或 ERP，互不影响。

1. 先设置（客服 → 知识库与话术）
   - 店铺政策：店铺名字、回复风格、发货时间、退换货、定制、批发折扣档（例如 10:5,30:10 = 10 个以上 95 折、30 个以上 9 折）。
     批发报价不会低于产品的最低售价（设置里的最低加价率）。
   - 常见问答：买家常问的问题和标准泰语回答。可以先写中文意思，点「把中文意思翻成泰语回答」。
   - AI 用设置页里的同一个 AI 接口密钥。
2. 客服工作台（不装扩展也能用）
   - 「＋ 新消息」：粘贴买家的话，或者上传聊天截图（AI 自己读出文字），也可以在会话里直接 Ctrl+V 粘贴截图。
   - 「🤖 AI 生成回复」：AI 根据产品资料（品名、颜色、尺寸、材料、售价）、订单状态、店铺政策、常见问答写泰语回复，
     下面有中文意思。可以写要求让它重写（例如「语气更正式」「告诉他明天发货」）。
   - AI 不会自己编价格、日期、运单号；退款、投诉、改订单会标「需人工」。
   - 消息里有订单号会自动关联订单，显示状态、最晚发货、生产进度、运单号。
   - 一键操作：定制要求写进订单的定制备注（中泰双语，生产工单上会显示）、记卖家备注、批发询价生成报价单、
     买家催单时设为加急、投诉时跳到订单登记售后。
   - 复制回复到平台发送，回来点「✓ 已发送」。员工实际发出去的回复会记下来（AI 原稿也保留对照），AI 下次参考。
3. 浏览器扩展（在 Lazada / Shopee / TikTok 卖家中心的聊天页面直接用，推荐）
   - 客服 → 知识库与话术 → 「⬇ 下载扩展」，解压到固定文件夹。
   - Chrome 打开 chrome://extensions → 打开「开发者模式」→「加载已解压的扩展程序」→ 选这个文件夹。
   - 老板在 客服 → 知识库与话术 → 「员工的扩展密钥」里给每个员工生成一个密钥（也可以在 系统 → 账号与对接 → API 与店铺对接 里建）。
   - 点 Chrome 右上角扩展图标：填软件地址（NAS：http://NAS的IP:8790；本机：http://127.0.0.1:8765）和密钥，选面板语言（中文/泰语），保存并测试。
   - 打开卖家中心聊天页面，右上角「💬 AI」：
     「读取对话」读当前买家的聊天记录 →（AI 写好回复）→「填入回复框」→ 在平台按发送。
     网页读不出来时用「截屏读取」（AI 看图识别）。面板可以拖动，不挡住发送按钮。
   - 面板上有三种模式（每个店铺网页各自记住）：
     · 手动：点「读取对话」才处理。
     · 半自动：买家一发消息，自动读取、写好回复、填进平台输入框，员工看一眼按发送（推荐先用这个）。
     · 全自动（托管）：简单问题（产品、价格、有没有货、物流、感谢）AI 有把握时，等几秒自动按发送；
       退款、投诉、改订单、定制、批发、AI 没把握的，不会自动发，会把回复填好、按钮变红闪烁、响一声、弹出系统通知，等员工处理。
       可以勾选「自动切换到有未读消息的买家」（实验功能），没在处理时自动点开有未读的买家逐个回复。
     · 「直接发送」按钮：一键填入并按平台的发送。
   - 老板在 客服 → 知识库与话术 → 自动回复 里控制：是否允许全自动、哪些类型可以自动发、AI 把握至少多少、
     每小时最多自动发几条（防止出错时乱发）、客服专用的 AI 模型（填 claude-haiku-4-5-20251001 这类小模型，回复更快更便宜）。
   - 只有员工确认过（人发的、改过的）回复才会被 AI 学习，自动发的不学，避免越学越偏。
   - 账号密码只在你们自己的浏览器里，扩展不会读取或保存。多个店铺：每个店铺用 Chrome 的一个「用户」分别登录，
     面板里「店铺」填上店名，同一个买家在不同店铺分开记。
   - 平台对机器人自动发消息有限制，建议先用半自动几天，看 AI 回复没问题再开全自动。以后申请到平台开放接口，可以改成接口直接收发。

十五、v2.4 新增
1. 软件改名「3D 运营管理系统」（泰语界面：ระบบบริหารจัดการ 3D）。数据、账号、设置都不变。
2. 文件管理（生产 → 文件管理）：所有产品的 3D 模型和切片文件在一个页面。
   - 每个产品一行：模型文件（预览 / 下载 / 替换 / 旧版本 / 删除）、切片文件（3D 预览 / 下载 / 替换 / 停用启用 / 删除）。
   - 「⬆ 批量上传模型」：一次选很多个文件，文件名以产品编号开头就自动对应（3DP0001.stl、3DP0001_猫咪.3mf）。
   - 替换模型：旧模型自动保存在「旧版本」里（最近 5 个），可以下载或恢复；这个产品的切片文件自动退回草稿，提醒重新切片 / 复核。
     上传模型时程序自动算体积和预估克数，不用再打开编辑页。
   - 替换切片文件：上传新版本，旧版本自动停用（不删除，随时可以再启用）。
   - 勾选产品 →「下载选中产品的全部文件（zip）」：每个产品一个文件夹，模型 + 切片文件。
3. 产品库：每行有「编辑 / 复制 / 删除」按钮，勾选后可以「删除选中」「下载模型和切片文件」「加入/移出分组」。
