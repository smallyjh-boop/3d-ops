# 模块：订单（orders）

订单（基础模块）：订单列表 / 导入 / 手工单 / 审单、打包核对、发货交接、售后、买家档案、每单利润、工作台数据、
打印订单 / 面单 / 交接单。订单变化通过 core/chain.py 发事件：生产模块生成生产任务、库存模块发货扣包材。

## 文件

- `__init__.py`
- `api.py`
- `module.py`
- `ui/aftersales.js`
- `ui/page.html`
- `ui/shipping.js`
