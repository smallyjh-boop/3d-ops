打包核对

先扫订单号或运单号（面单上的条码），再逐个扫商品工单贴纸上的 SKU 条码。全部对上了才能点「打包完成」，防止错发漏发。 扫码枪直接扫；手机可以点「📷 摄像头扫码」。

发货交接

快递员上门揽收或送到网点时用：选物流，逐个扫包裹面单上的运单号（或订单号），扫完核对件数，点「交接完成」——单里的订单全部标记「已发货」。 取消了 / 拒收的 / 还在待审核的订单扫进来会报警，防止发错。可以打印交接单让快递员签字。

售后

在订单详情里点「登记售后」。每条售后按流程走：待处理 → 等买家寄回 / 等平台判定 → 已收到待验货 → 已退款 / 已补发 / 已拒绝 / 已关闭。 有处理期限（平台一般 48 小时要回应），快到期和超期的标红。退回来的货要验货：能卖的放回成品库存，坏的报废记损失。拒收 / 派送失败的订单会自动登记一条，等包裹退回。 责任方和打印机会统计到「质量统计」，损失会从「利润」里扣掉。

买家档案

同一个买家（同电话，或同平台同账号）的历史订单自动归在一起：下过几单、拒收几次、退货几次。可以标记 VIP、批发客户、需留意、黑名单。 黑名单和拒收过的买家再下货到付款单时，会自动挂起到「待审核」。这里只列出有分类、拒收过、或下过 2 单以上的买家。
