# 模块：生产（prod）

生产：生产看板（排单、打印批次）、打印机（连接、状态、保养）、文件管理、打印方案 / 切片文件、质量统计、
耗材料卷（补货计划）、成品备货。接订单模块的事件 order.changed（生成生产任务）和 chain.reschedule（重新排单）。
关掉后：新订单不生成生产任务、不轮询打印机；订单照常导入、发货。

- 1.11（系统 v2.53.0）：没有订单也能生产 / 试打（core/trial.py，ui/trial.js，测试 t_trial253.py）：
  ① 「➕ 生产」备货任务从任何入口建：产品编辑页每个 SKU、产品库勾选栏、商品 360 抽屉、生产看板「➕ 新建任务」（接口 POST /api/jobs/stock，旧的 /api/stock/make 也带 priority / printer / source）；可以加急、指定打印机；和订单任务同一套流程（排单、核对、打印、质检 → 待检区 → 入库）。
  ② 「🧪 试打」任务（jobs.kind = trial，POST /api/trial）：打印方案每一盘的「🧪 试打这一盘」、文件卡片、产品库勾选（只给还没试打验证的盘）；选同机型的空闲打印机，这一盘没有文件现在按方案切片；排在最前面，可以用还没试打验证的文件开始（开始对话框不要求复核），机型 / 喷嘴 / 热床板 / AMS 核对照旧，机型不对的文件建任务时就拒绝；几盘的产品每盘一个试打任务。打完（任务进「后处理」栏，试打记录 trials 状态「等结果」）填「试打结果」（电脑 + 手机 /m「试打结果」）：成功 / 失败、问题勾选（翘边、支撑难拆、拉丝、尺寸不对、颜色不对、掉层、其他）+ 说明、实际克数 / 时长（按批次预填）、照片；成功 → 文件自动「已试打验证」，实际克数 / 时长写回款式（printplan.apply_actual，grams_src=trial，成本更新）；去向：合格入库（只有一盘的产品；→ 待检区 → 质检合格才可售）/ 当样品（不可售，记录）/ 报废；失败 → 记原因、文件退回草稿，提示改方案重新切片，「再试一次」。打印中途点「失败」也记为试打失败。每个产品的试打记录（次数、成功率、常见问题、照片）在商品 360 和编辑页打印方案下面。
  ③ 「🔍 检查切片文件」（POST /api/trial/check-file，不打印）：用这一盘现有的文件（没有就先切）核对机型 / 喷嘴 / 热床板（slicecheck）、克数 / 时长和估算（差 40% 以上提醒）、第一层所有路径在热床内且不压拓竹废料口（printplan.exclude_of）、颜色槽和方案是否一致；画第一层俯视预览（红色 = 废料口）；通过后一键「🧪 试打这一盘」。
  ④ 设置 → 生产 → 打印机连接「🧪 打印测试」（POST /api/printers/N/print-test）：给这台打印机的机型用 OrcaSlicer 切 20 mm 立方体（同机型复用），走正常发送 / 开始路径（jobs.kind = test），打完回报后任务结束（不进库存）；没装 OrcaSlicer / 没设连接 / 离线 / 在打印都有清楚提示。
  ⑤ 看板：类型标签 订单 / 备货 / 试打 / 测试（不同颜色）+ 按类型筛选，等结果的试打在看板顶上提示。备货 / 试打 / 测试只有老板和生产角色能建（别的角色 403）。
