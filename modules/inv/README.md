# 模块：库存（inv）

库存：库存管理（物品、采购入库 / 领用 / 报废 / 调整单据、盘点、流水、库存报表）、发货自动扣包材、
打印扣耗材和成品增减同步记流水、给财务的事件接口。数据在 core/inventory/。
接订单模块的事件 order.status（已发货 → 扣包材）。关掉后：不再记库存流水、不扣包材 / 备件，耗材料卷照常（生产模块）。

## 文件

- `__init__.py`
- `api.py`
- `events.py`
- `module.py`
- `ui/inventory.js`
- `ui/page.html`

## 改动记录

- 1.0（系统 v2.31.0）：从内核拆成模块。
- 1.1（系统 v2.32.0）：库存页分「库存」和「物品资料」（views.py）：没入过库的物品不堆在库存里、不发补货提醒；每个分类显示自己的列。
- 1.2（系统 v2.33.0）：货位管理（locations.py、ui/locations.js）：批量建货位、按分类区自动上架、出库先扣未上架、移库、核对、货位标签、拣货单按货位排序。
- 1.3（系统 v2.34.0）：货位改成「区 + 货架号 - 层 - 位」（A1-02-03 = A区 1号货架 第2层 第3位）：按货架建（几层 × 每层几位），货架 / 区可以设名字和放哪些分类，加一层 / 某层加一位 / 删空的层和货架，页面按货架画（一行一层，「地面」在下面，层号方向可设置），扫货架码高亮、扫物品码显示放在哪，货位标签带「A区 1号货架 第2层 第3位」，货架牌；自动上架不会把东西塞进指定给别的分类的货架；v2.33 的旧编号自动迁移（A-01-03 → A1-01-03），旧标签照样能扫。泰文翻译从内核 static/i18n.js 搬到模块自己的 i18n/th.json（只在这个模块里用到的那些），界面不变。
