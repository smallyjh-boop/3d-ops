# 模块：库存（inv）

库存：库存管理（物品、采购入库 / 领用 / 报废 / 调整单据、盘点、流水、库存报表）、货位（一个物品一个货位）、
订单发货出库（成品 + 纸箱 + 包材，每单一张出库单）、邮政纸箱用量、打印扣耗材和成品增减同步记流水、给财务的事件接口。
数据在 core/inventory/。接订单模块的事件 order.status（已发货 → 开出库单；改回待发货 → 作废冲回）。
对外（modules.public("inv")）：on_post（入库自动放货位）、where_is、sort_key、human、order_out（订单详情里的出库单）。
关掉后：不再记库存流水、不扣包材 / 备件，耗材料卷照常（生产模块）。

## 改动记录

- 1.0（系统 v2.31.0）：从内核拆成模块。
- 1.1（系统 v2.32.0）：库存页分「库存」和「物品资料」（views.py）：没入过库的物品不堆在库存里、不发补货提醒；每个分类显示自己的列。
- 1.2（系统 v2.33.0）：货位管理（locations.py、ui/locations.js）：批量建货位、按分类区自动上架、出库先扣未上架、移库、核对、货位标签、拣货单按货位排序。
- 1.3（系统 v2.34.0）：货位改成「区 + 货架号 - 层 - 位」（A1-02-03 = A区 1号货架 第2层 第3位）：按货架建（几层 × 每层几位），货架 / 区可以设名字和放哪些分类，加一层 / 某层加一位 / 删空的层和货架，页面按货架画（一行一层，「地面」在下面，层号方向可设置），扫货架码高亮、扫物品码显示放在哪，货位标签带「A区 1号货架 第2层 第3位」，货架牌；自动上架不会把东西塞进指定给别的分类的货架；v2.33 的旧编号自动迁移（A-01-03 → A1-01-03），旧标签照样能扫。泰文翻译从内核 static/i18n.js 搬到模块自己的 i18n/th.json（只在这个模块里用到的那些），界面不变。
- 1.4（系统 v2.35.0）：货位简化成「一个物品一个货位」：数量只记在物品上（inv_items.location），在物品资料里选货位和在格子里「放物品」是同一件事；格子显示有货 / 用完了 / 低于补货线 / 空，点格子可以入库、出库、换货位、放物品、盘点；「新建货架」可以一次建几个；新物品第一次入库自动放到这个分类的货架的空格（on_post）；去掉未上架 / 按格子记数 / 核对，改成按货架盘点（stocktake 的 area）；v2.33 / v2.34 的数据自动迁移（放得最多的那个货位）。订单发货出库（shipout.py）：订单变成已发货时开一张「订单出库」单（CK…）：用库存发的成品 + 订单的邮政纸箱 + 设置里每单 / 每件的包材，改回待发货作废冲回，每单只出一次；原来的「发货自动扣包材」合并进来。库存页加「纸箱」（views.box_stats）：每种邮政纸箱的库存、近 30 天 / 本月用量、还够几天，一键建档。
