# 模块：3D 模型（model）

3D 模型（基础模块）：产品的 3D 模型上传 / 预览 / 历史、模型库（多个文件、拼盘）、规格对应的模型、几何分析、
AI 打印建议、估算克数和时长（切片估算）。编辑产品页里的 3D 部分（界面代码 v2.32 从 app.js 拆出来）。

## 文件

- `__init__.py`
- `api.py`
- `module.py`
- `assembly.py`：展示模型（每个规格的零件选择、组装姿势、缩放、自动选零件、爆炸图、AI 按图片组装）
- `mating.py`：按几何形状自动组合（高度图贴合 / 插接，置信度）、沉降、爆炸方向
- `printplan.py`：打印方案（盘、摆盘、AMS、缩放规格、从组装生成、一键全部切片、概览）
- `ui/model.js`、`ui/plan.js`、`ui/m3.js`（③ 规格切换 + 概览 + 收起的摘要）、`ui/assemble.js`（组装视图，按需加载）

- 1.2（系统 v2.52.0）：分三层：模型文件库（原始文件）→ 展示模型（assembly.py：多零件「组装」视图，three.js TransformControls 拖动 / 旋转零件，「AI 按图片组装」初稿（DeepSeek 不能看图会提示），保存后 3D 预览和商品图按组装好的样子出）→ 打印方案（printplan.py：每个规格几盘，每盘打印机 / 层高 / 出几套 / AMS 槽（最多 4 个），手动摆盘：热床俯视图拖动 / 旋转 / 复制零件，重叠 / 超出热床标红，「自动排列（省空间）」「组合摆盘（按说明 / AI）」；配色方案（款式 → 槽颜色）；按零件分色；涂色 3MF 原样保留、读 slice_info 每种耗材用量；没有切片时按体积估克数 + 按换色次数估冲刷废料（设置 mc_purge_g / mc_change_s，标「估」）；下载这一盘 3MF（位置 + 每个零件的耗材槽）、按这一盘切片（OrcaSlicer，多色时多份耗材配置 + 擦料塔）、合并成一套用摆好的位置、按方案填变体克数时长）。生产 / 成本 / 扣耗材按方案（public: printplan）。
- 1.3（系统 v2.53.0）：展示和打印完全分开：展示有自己的零件选择（模型库任意文件 / 组件 + 数量），「合并成一套（设为模型）」只影响打印；主模型是合并出来的（parts_of）而展示没自己选零件时，自动拆回原来的零件（老产品读取时就转，包括 v2.52 旧的 display 格式）。每个规格（款式 / 带不带盖 / 几个装 / 不同零件…）各有展示和打印方案：③ 顶部规格切换 + 规格 × 状态概览表（展示设没设、方案 未保存 / 估 / 已切片、克数、时长、成本，点一行切过去）；「从某个规格复制」；「按主模型缩放 N%」（展示和打印都跟着主模型缩放，克数按 k³ 估，不用另外的文件）。组装视图：左边零件选择（勾选 + 数量）、「自动选零件」（按规格对应的模型 / 文件零件名、x4 数量、无盖去掉盖子、2 个装 ×2、去掉支撑 / 测试件）、「自动组合」（mating.py：24 个朝向 × 高度图落下，算贴合面积和插进去多深，盖子盖上、头的插销插进身体；给置信度，低时提示用 AI，AI 结果再按几何落下贴合）、「落下贴合」、爆炸图 + 零件说明图、撤销 / 重做（Ctrl+Z / Ctrl+Y，组装视图和摆盘都有）。组装视图和摆盘画布默认收起（一行摘要 + 缩略图，点「查看 / 编辑」才加载 three.js / 读方案），页面更快。「从组装生成打印方案」（展示的零件按推荐方向平放、自动排盘，放不下自动分盘）；「一键全部切片」（后台按顺序切每个规格的每一盘，进度，切完按方案填变体克数 / 时长）。自动排列避开拓竹 X1 / P1 左前角的废料口（以前排到角上 OrcaSlicer 会说「盘上没有能切的零件」），摆盘画布画出这块区域。
