手动改上架状态（用表格上传的产品；标的是当前平台）

上架批次

每次导出表格 / 接口推送是一个批次。用表格上传的：在平台上传完文件后点「整批上传成功」（变成平台审核中）；在平台后台看到过审后点「整批审核通过」（变成已上线）；个别没过的展开后单独标记。

库存待同步到平台

开了「按耗材自动算库存」的产品：耗材用掉 / 进货后，库存变化够多的 SKU 列在这里。 用「直接推送到 Lazada」上架的产品：点「推到 Lazada」或按 设置 → 商品 → Lazada 接口推送 的间隔自动改； 用表格上传的产品请到平台后台改好库存后点「已改好」。导出上架表格 / 推送时的库存自动记为已同步。

价格 / 促销价 / 库存直接改到平台，同时写回 ERP（售价两边一致；开了「按耗材算库存」的产品，库存还是按耗材算）。 改标题、详情、图片、属性：点「编辑资料」在 ERP 里改，改完点「更新到店铺」。
