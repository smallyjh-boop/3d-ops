1. 选择要导出的产品

按分组分批上架：先筛选分组 / 状态，勾选后导出。导出后产品自动变成「待上传」；上传到平台后是「平台审核中」，过审后标「已上线」，没过审标「审核不通过」（写上原因）。同一个模板里的多个类目会写进同一个文件。

已选 0 个 ｜标记 （标记的是上面所选平台）

3. 上架批次

每次导出是一个批次。在平台上传完文件后点「整批上传成功」（变成平台审核中）；在平台后台看到过审后点「整批审核通过」（变成已上线）；个别没过的展开后单独标记。

4. 库存待同步到平台

开了「按耗材自动算库存」的产品：耗材用掉 / 进货后，库存变化够多的 SKU 列在这里。 现在请到平台后台改好库存后点「已改好」；以后接上 Lazada 接口会自动推送。导出上架表格时表格里的库存自动记为已同步。
