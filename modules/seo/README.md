# 模块：搜索优化（seo）

搜索优化——v2.30 从内核搬出来的模块。

编辑页的搜索分、AI 搜索优化（关键词 + 标题 + 详情 + 标签，直接更新可以撤销）、AI 打分和建议；
产品库的搜索分小标签、批量搜索优化。关掉后产品库不算搜索分，编辑页不显示这些按钮，产品资料不受影响。
