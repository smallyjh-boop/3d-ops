# 模块：采购（pur）

采购——v2.30 从内核搬出来的模块。

v2.51 起一个页面三个页签：**补货建议 · 采购单 · 到货入库**（顶部数字卡片：在途金额、还没付清、本月到货、本月付款）。

- 补货建议：耗材按还没打的生产任务 + 近 30 天扣料，包材按近 30 天用量 × 订单量变化（和发货扣包材规则取大的），其他按近 30 天出库；
  算还能用几天、到货天数（物品的供应商 → 供应商 → 设置），红（来不及）/ 黄（该下单）/ 绿；建议数量按起订量、包装数、整卷取整；
  勾选后一键按供应商生成采购单草稿。
- 采购单：草稿 → 已下单·在途（物流单号、预计到货、倒计时）→ 部分到货 → 已入库 → 完成（入库 + 付清 + 差异处理完自动完成）；
  取消、退货给供应商（采购退货单，不算支出）、供应商退款；人民币下单 + 下单时的汇率（默认用「人民币兑泰铢汇率」）；
  供应商运费、进口税、国际运费 / 其他费用按金额分摊进到手单价；分次付款，每笔自动记到财务；列表 / 看板，按 未付清 / 已付清 / 过期 筛选。
- 到货入库：扫采购单号 / 物流单号 / 平台订单号 / 物品条码（电脑扫码枪或手机 /m →「采购到货」），填这次到了多少，
  少发 / 破损 / 发错 / 多发记成差异（少发、破损的不进库存），顺便放货位，打印物品标签（/print/pur-labels）。
- 供应商不单独一页：下拉里选，「＋新供应商」「管理」（没用过的删除，用过的停用）。
- 物品 ↔ 供应商（「⋯ 采购资料」，库存的物品弹窗里也有入口）：购买链接（1688 / 淘宝 / 拼多多 / Shopee / Lazada）、最近单价、起订量、包装数、
  到货天数、首选供应商（= 物品的默认供应商）、价格历史、比价（按到手单价）。
- 到货后：记价格历史；耗材平均进价变化超过设置的百分比 → 自动更新定价用的「耗材价格（人民币/公斤）」（可以关成只提醒），给老板一条待办。
- 🤖 识别订单开单：贴订单文字或截图，AI（core/ai_copy）读出供应商、商品、数量、单价、运费、订单号 / 物流单号 → 可以改的草稿，
  商品按名字对到库存物品，对不上的可以新建。
- 采购分析（📊）：按月 / 分类 / 供应商的采购金额、每月付款、耗材每公斤到手价走势、最便宜的供应商、成本变化。
- 今日待办：过了预计到货没到、到货差异没处理、来不及到货的物品、进价变化。

采购单的数据、到货入库、到货差异、付款在内核的库存里（core/inventory/purchase.py，库存流水只能通过单据改变），关掉采购模块库存照常用；
采购模块自己的表（物品 ↔ 供应商、价格历史、成本变化）在 logic/store.py，第一次打开时自动迁移老数据（供应商的货币 / 平台、物品的默认供应商和购买链接、已到货的采购单 → 价格历史）。
旧的菜单 id（po_suggest / po_suppliers / po_pay）还能打开，跳到对应的页签。
