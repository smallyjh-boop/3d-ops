# 模块：采购（pur）

采购——v2.30 从内核搬出来的模块。

采购单（下单、物流单号、到货入库、付款）、补货建议（按库存和在途算该买多少，一键生成采购单）、供应商、付款记录。
采购单的数据和到货入库在内核的库存里（库存流水只能通过单据改变），关掉采购模块库存照常用。
